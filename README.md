# Assignment #4 — Forms and Validation

A responsive multi-page website demonstrating HTML forms, native HTML5 validation, Bootstrap form styling, and Bootstrap validation feedback.

## Pages

- `index.html` — project homepage and navigation
- `task0.html` — simple contact form with labels
- `task1.html` — contact form using HTML5 validation attributes
- `task2.html` — Bootstrap contact form and responsive grid
- `task3.html` — Bootstrap validation styles and feedback messages
- `task4.html` — registration form with password confirmation, radio buttons, checkboxes, and country dropdown
- `style.css` — custom styling

## How to run

1. Download or clone this repository.
2. Open `index.html` in a browser, or use the Live Server extension in Visual Studio Code.
3. An internet connection is needed to load Bootstrap from its CDN.

## Publish with GitHub Pages

1. Push all project files to a GitHub repository.
2. Open the repository's **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)` folder, then save.
5. Wait for deployment and open the published URL.

## Notes

This is a front-end educational demo. Forms validate user input in the browser but do not send or store messages or registration data on a server.
